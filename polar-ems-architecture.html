Getting this into PowerPoint

  1. Copy the source block for whichever diagram you want (button above each).
  2. Open mermaid.live, paste it into the left-hand editor pane — the diagram renders instantly on the right.
  3. Use its Actions → PNG (or SVG, for a version that stays sharp if you resize it on the slide) to download the image.
  4. Insert that image into your slide like any picture — Insert → Pictures in PowerPoint.
